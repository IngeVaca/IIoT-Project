Dashboard Implementation - Embedded Architecture

Primary Function
This single-file HTML dashboard implements a complete IoT monitoring interface with embedded CSS and JavaScript. It provides real-time visualization of electrical parameters, data management capabilities, and MQTT communication without external file dependencies.

Embedded Architecture Design

Single-File Structure
- HTML5 markup with embedded style and script sections
- Self-contained CSS within <style> tags
- Integrated JavaScript within <script> tags
- No external file dependencies for core functionality
- CDN resources only for external libraries (Chart.js, Paho MQTT)

Advantages of Embedded Approach
- Simplified deployment - single file distribution
- No cross-origin resource sharing issues
- Consistent styling and behavior guarantee
- Easy version control and sharing
- Reduced HTTP requests for better performance

Technical Implementation

CSS Architecture
- Base reset and typography rules
- Flexible grid and container layouts
- Component-specific styling (cards, charts, controls)
- Responsive design for various screen sizes
- Professional color scheme and visual hierarchy

JavaScript Architecture
- MQTT communication handlers with automatic reconnection
- Chart.js initialization with multiple Y-axes
- Data capture management with configurable limits
- CSV export functionality with timestamp generation
- Power triangle visualization using Canvas API

Component Integration

Real-time Data Flow

1. MQTT message reception via WebSocket connection
2. JSON parsing and data validation
3. DOM updates for parameter display cards
4. Chart data series appending and maintenance
5. Power triangle canvas rendering with vector calculations
6. Status indicator and progress bar updates

Visualization Synchronization

- Coordinated updates across all display components

- Responsive layout preservation during updates
- Smooth animation synchronization

Usage Instructions

Initial Setup

1. Open the HTML file in any modern web browser
2. Update MQTT broker configuration in the script section
3. Configure academic information in the credentials section
4. Set data capture limits according to requirements
5. Verify topic subscription matches gateway publication

Operational Procedure

1. Browser automatically establishes MQTT connection
2. Monitor connection status indicator
3. Configure data capture settings as needed
4. Start data capture when ready to record
5. Observe real-time parameter updates and visualizations
6. Export captured data via CSV when desired

Maintenance Considerations

- Regular verification of MQTT broker accessibility
- Browser cache clearing for updates
- Data backup procedures for captured information
- Performance monitoring with large datasets
- Compatibility testing with browser updates
